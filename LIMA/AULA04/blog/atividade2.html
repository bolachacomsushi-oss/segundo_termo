Como aprender HTML

Publicado em 10/10/2026 por Ana

HTML não é uma linguagem de programação; é uma linguagem de marcação, usada para definir a estrutura do seu conteúdo. HTML consiste de uma série de elementos, que você usa para delimitar ou agrupar
diferentes partes do conteúdo para que ele apareça ou atue de determinada maneira. As tags anexas podem transformar uma palavra ou imagem num hiperlink, pode colocar palavras em itálico, pode aumentar ou diminuir a fonte e assim por diante.
Tudo no HTML funciona com tags (etiquetas) abertas por < e fechadas por >. A maioria exige uma tag de fechamento com /.

As Principais Tags para Decorar

Títulos (de h1 até h6): Funcionam como as manchetes e subtítulos de um jornal. O h1 é a manchete principal da página e o h2 é o subtítulo da primeira folha.
Exemplo de uso: Você usa h1 para o nome do seu site (como "Portal de Notícias") e h2 para o título de uma matéria ("Novas vagas de tecnologia abertas").

Links (tag a com href): É o botão ou a palavra que você clica para ser levado a outro site ou página.
Exemplo de uso: Uma palavra azul escrita "Clique aqui para baixar o PDF" que, ao ser clicada, abre o link do arquivo configurado dentro dela.

Imagens (tag img com src e alt): Coloca uma foto na tela. O "src" avisa ao navegador o endereço da foto e o "alt" é um texto que descreve a imagem caso ela não carregue ou para pessoas com deficiência visual que usam leitores de tela.
Exemplo de uso: Uma foto do seu rosto em uma página de contatos, onde o texto alternativo diz "Fotografia de rosto sorrindo".

Listas (tag ul para abrir a lista e li para os itens): Organiza tópicos em formato de itens com bolinhas.
Exemplo de uso: Uma lista de supermercado onde a estrutura principal cria o espaço e cada item da lista (como arroz, feijão e batata) ganha uma bolinha automática ao lado.

Divisões (tag div): Funciona como uma caixa de papelão invisível que você usa para guardar vários objetos juntos dentro do armário, ajudando a organizar o espaço.
Exemplo de uso: Você coloca um título, uma foto e um preço dentro de uma mesma caixa (div) para criar o cartão visual de um produto em uma loja virtual.
